## 🤖 Featured: Facebook Auto-Post con Gemini

Esta automatización permite transformar una idea simple en un post de Facebook completo, optimizado y visualmente atractivo de forma totalmente autónoma.

### 🛠️ ¿Cómo funciona?
El flujo de trabajo sigue estos pasos:
1. **Trigger:** (Configurable) Puede activarse desde una fila en Google Sheets, un mensaje de Telegram o un webhook.
2. **Gemini AI:** Procesa el tema y genera un copy persuasivo ajustado a la voz de tu marca.
3. **Media Generation:** Gemini genera o selecciona la pieza visual para acompañar el texto.
4. **Facebook API:** Publica el contenido final de forma automática en tu página o grupo.

### 📦 Requisitos Previos
Para usar este blueprint, necesitarás:
* Una cuenta activa en **Make.com**.
* **Google Gemini API Key** (obtenida en Google AI Studio).
* Una **Fanpage de Facebook** con permisos de administrador.

### 🚀 Instrucciones de Instalación
1. Descarga el archivo `.json` correspondiente en este repositorio.
2. Ve a tu dashboard de Make y crea un **Nuevo Escenario**.
3. En el menú de herramientas (iconos inferiores), haz clic en los tres puntos (**More**) y selecciona **"Import Blueprint"**.
4. Carga el archivo `.json` descargado.
5. Configura tus conexiones: vincula tu API Key de Gemini y tu cuenta de Facebook en los módulos marcados.
